## הבוחן — 8.9.2026

- 5 היגדים "נכון / לא נכון" + נימוק (סעיף חוק / פס"ד), כחצי שעה
- **חומר פתוח אך ללא מחשבים** — רק חומר מודפס. יש להדפיס את החוברת ואת קובץ החקיקה מראש.
- היקף: מצגת מבוא + מצגת 1 (ס' 1–12, זיכרון דברים, תום לב, פ"ד קוזלי) + מצגת 2 עד ס' 14(ב), וכן ס' 19–21

⚠️ חלק מהחומרים בתיקיית `למבחן` הם חומרי קורס של המרצה וכוללים סימון "כל הזכויות שמורות" — המאגר נועד לסיוע לסטודנטים בקורס בלבד.
